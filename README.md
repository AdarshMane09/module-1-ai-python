## Topics Covered

### Artificial Intelligence

Artificial Intelligence (AI) is a technology that enables computers and
machines to perform tasks that normally require human intelligence.

Examples:
- Chatbots
- Voice assistants
- Recommendation systems
- Self-driving vehicles
- Image recognition

### Machine Learning

Machine Learning (ML) is a subset of AI that allows computers to learn
patterns from data and make predictions or decisions.

### Deep Learning

Deep Learning is a subset of Machine Learning that uses artificial neural
networks with multiple layers to learn complex patterns.

## AI vs ML vs Deep Learning

| Technology | Meaning |
|---|---|
| AI | Broad field of making machines intelligent |
| ML | Machines learn from data |
| Deep Learning | ML using multi-layer neural networks |
